LLM chat tools for querying [Seq](https://datalust.co/seq): query events, list signals, and run SQL
queries from an LLM agent.

> **Disclaimer**: This package was written entirely by AI. Use at your own risk.

## Features

- `seq_query_events` - query events with a Seq filter expression
- `seq_run_query` - run a SQL query and return the rows as CSV
- `seq_list_signals` - list signals and their filter expressions

## Prerequisites

- Node.js >= 20.9

## Installation

```bash
npm install @johannes.latzel/llm-chat-seq
```
